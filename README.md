# 🚗 Car Price Prediction App

This is a Machine Learning web app built using **Streamlit** that predicts the selling price of a used car.

## 🔧 Technologies Used

* Python
* Scikit-learn
* Pandas, NumPy
* Streamlit

## 🚀 Features

* User-friendly UI
* Real-time prediction
* Handles categorical data using encoding

## ▶️ Run Locally

```bash
streamlit run app.py
```
